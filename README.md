# Larm

Larm — a UTC-only alarm &amp; timer app for gaming groups across timezones. Every alarm fires at its UTC instant and the dashboard shows only UTC time, so there's no ambiguity when travelling or coordinating across regions. Set custom alarms/timers, see live countdowns, and get full-screen alerts that respect your phone's sound settings. A single dark Aurora glass theme with clear Lucide icons keeps the interface calm and legible. No login required — just open and go.

## Highlights

- **UTC only** — no device-local clock or local alarm mode; the dashboard, editor preview, and ringing screen all show UTC.
- **Dark Aurora glass** — one theme, deep indigo-black glass with violet, cyan, and mint accents.
- **22 bundled tones** — 12 original classics plus 10 royalty-free "Popular" tones synthesized locally (`dart run tools/generate_sounds.dart`).
- **Live timers and full-screen alerts** — alarms and timers keep running after the app is killed, with snooze controls and notification actions.
- **Local-only, no auth** — all data stays on the device.
